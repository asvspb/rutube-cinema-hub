## Rutube Cinema Hub — локальный запуск (dev-сервер)

> **Дата создания:** 2026-02-09  
> **Последнее обновление:** 2026-02-17  
> **Статус:** ✅ Актуально

### Цель

Запустить фронтенд в режиме разработки через Vite dev-server.

### Порты (принятое соглашение)

- **App (frontend, Vite dev-server): 9229**
- **API/Proxy server (Express, `server/index.js`): 9230**
- **DB (план): 9009**

> Примечание: бэкенд (`server/index.js`) нужен для эндпоинтов `/api/*` (прокси Rutube, логирование, KinoRate AI).

---

### Требования

- Node.js **18.19+ / 20+**
- npm

Проверка:

- `node -v`
- `npm -v`

---

### Установка зависимостей

В корне проекта:

- `npm install`

---

### Переменные окружения (опционально)

Если вы используете **KinoRate AI** (LLM) функции (см. эндпоинты в `server/index.js`), создайте файл `.env.local` в корне проекта:

```bash
# Gemini (по умолчанию)
GEMINI_API_KEY=ВАШ_КЛЮЧ
GEMINI_MODEL_NAME=gemini-2.5-flash

# Mistral (опционально)
MISTRAL_API_KEY=ВАШ_КЛЮЧ
MISTRAL_MODEL_NAME=mistral-medium-2505
MISTRAL_ENABLED=true

# Общие настройки LLM
LLM_PROVIDER=auto   # gemini | mistral | auto
LLM_TIMEOUT_SEC=30
LLM_MAX_TOKENS=512
```

Важно:

- не коммитьте ключи;
- не вставляйте ключи в логи.

---

### Запуск API/Proxy сервера (backend)

В отдельном терминале:

- `node server/index.js`

Ожидаемый адрес:

- `http://localhost:9230`

---

### Запуск dev-сервера

Команда:

- `npm run dev`

> Если запускаете через `docker-compose up`, фронтенд автоматически дождётся готовности backend (эндпоинт `/api/health`).

Ожидаемый адрес:

- `http://localhost:9229`

Параметры dev-сервера задаются в `vite.config.ts`.

---

### Мини-проверка после запуска

1. Проверить, что сервер слушает порт:

- `curl -I http://localhost:9229`

2. Открыть страницу в браузере:

- `http://localhost:9229`

---

### Примечание про Rutube / CORS

Фронтенд использует «гибридное проксирование»:

1. сначала пытается обратиться к локальному эндпоинту `/api/proxy?url=...`;
2. если локальный прокси недоступен, переключается на публичные CORS-прокси.

Поэтому:

- dev-сервер может успешно стартовать без бэкенда, но эндпоинты `/api/*` (proxy/logs/KinoRate AI) будут недоступны;
- в некоторых сетях загрузка данных Rutube может быть нестабильной (это отдельная задача — поднять свой `/api/proxy`).

---

### Troubleshooting

#### Порт 9229 занят

Запустить на другом порту без изменения репозитория:

- `npm run dev -- --port 9231`

#### Ошибка `vite: not found`

Означает, что зависимости не установлены:

- выполните `npm install` в корне проекта.
