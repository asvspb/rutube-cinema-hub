# Техническое задание: Упрощение формы авторизации

## 1. Анализ текущего состояния

### Существующая реализация:

- **Frontend**: `AuthModal.tsx` — использует email + сложный пароль (min 8 символов, верхний/нижний регистр, цифры, спецсимволы)
- **Backend**: `authService.js` — регистрация через email + password
- **База данных**: Prisma schema с полями `email` (unique), `passwordHash`
- **Валидация**: Email формат, сложность пароля, подтверждение пароля

## 2. Требуемые изменения

### 2.1 Изменение концепции

| Параметр              | Было                       | Станет                 |
| --------------------- | -------------------------- | ---------------------- |
| Логин                 | Email                      | Никнейм (username)     |
| Пароль                | Min 8 символов + сложность | Min 6 символов (любые) |
| Подтверждение пароля  | Обязательно                | Убрать                 |
| Индикатор силы пароля | Есть                       | Убрать                 |

### 2.2 Изменения в базе данных

**Файл**: `prisma/schema.base.prisma`

```prisma
model User {
  id           String    @id @default(uuid())
  username     String    @unique  // вместо email
  passwordHash String
  isActive     Boolean   @default(true)
  // ... остальные поля
}
```

### 2.3 Изменения в Backend

**Файлы**:

- `server/services/authService.js` — заменить email на username в функциях `registerUser`, `loginUser`
- `server/routes/auth.js` — обновить маршруты
- `server/schemas/authSchemas.js` — обновить валидацию

### 2.4 Изменения в Frontend

**Файлы**:

- `src/components/Auth/AuthModal.tsx`:
  - Поле "Email" → "Никнейм"
  - Убрать валидацию email формата
  - Убрать поле "Подтверждение пароля"
  - Убрать индикатор силы пароля
  - Минимум 6 символов для пароля
  - Убрать подсказки по требованиям к паролю

- `src/services/authService.ts` — изменить типы и API вызовы (email → username)
- `src/contexts/AuthContext.tsx` — обновить типы

### 2.5 Изменения типов

**Файл**: `src/types/index.ts`

```typescript
interface User {
  id: string;
  username: string; // вместо email
  // ...
}
```
