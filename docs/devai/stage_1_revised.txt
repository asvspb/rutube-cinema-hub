Stage 1 (Revised) — Detailed Refactor Guide

Purpose
- Convert App.tsx into a pure composition layer that wires hooks and components only.
- Remove business logic from App.tsx.
- Use existing hooks; do not invent new architecture.
- Align with TODO.md Phase 1–4 checklist (this guide is the narrative companion to that task list).

Important Context (Read First)
- docs/ARCHITECTURE.md
- docs/STATE_MANAGEMENT.md
- docs/PROXY_SECURITY.md
- src/services/rutubeService.ts (proxy + data loading)
- server/index.js (proxy security + /api/proxy)
- docs/devai/stage_1.txt (original scope)

Observed Gaps (Current State)
- App.tsx still contains state, effects, handlers, and computed values.
- useAppComposition duplicates App.tsx logic, but App.tsx does not use it.
- useChannelMenu contains placeholder logic for rename/remove.
- filteredVideos/sortedVideos are duplicated in useAppComposition.

Target End State
- App.tsx is a composition-only file.
- useAppComposition is the single place for state, effects, and computed values.
- useChannelMenu performs real rename/remove via useChannels handlers.
- No duplicate computed blocks.

-----------------------------
A) Migration Map (App.tsx → Hooks)
-----------------------------
1) State (move to useAppComposition)
- channels, activeChannelId, viewMode, activeCategory
- videos, videoCache, nextPageUrl
- isVideoLoading, isLoadingMore, isFetchAllMode, refreshKey
- isLoggedIn, videoWatchedStatuses, videoLikedStatuses
- watchHistory
- metadataCache, loadingMetadataFor
- gridColumns, sortOption, sortDirection
- searchQuery, isSearchOpen
- selectedVideo
- all modal flags and payloads
- channel menu state: activeChannelMenuId, channelMenuPosition, isEditingChannel, channelEditName
- channelInfo, isChannelLoading, channelAvailablePlaylists
- ratingSettings, currentPage

2) Effects (move to useAppComposition)
- StorageService.set* effects
- activeChannelId correction when channels change
- activeCategory updates when playlists change
- search reset when category changes
- search input focus effect
- click-outside/scroll close logic for menus

Criteria for done (useAppComposition vs App.tsx)
- useAppComposition owns: all state, effects, computed values, handlers, derived props.
- App.tsx owns: only composition wiring (hook call + prop plumbing + render).
- App.tsx must not import useState/useEffect/useMemo/useCallback/useRef except for composition helpers (if any).
- App.tsx should stay ≤ 300 lines and contain no conditional business logic.

3) Computed values (move to useAppComposition)
- filteredVideos, sortedVideos, displayedVideos, totalPages
- any helper computed for grid layout

4) Handlers (move to useAppComposition or existing hooks)
- handleAddPlaylist, handleRenamePlaylist, handleRemovePlaylist, handleReorderPlaylists
- handleVideoClick, handleVideoClickForHistory
- keep handleRefresh from useVideoLogic
