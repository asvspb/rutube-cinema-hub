# Подробный план реализации для AI-агентов (обновлённый)

## 0. Согласование со структурой проекта
Текущая структура отличается от целевой (`App.tsx` и `server.js` в корне). План начинается с этапа миграции.

### 0.1 План миграции
1. Перенести frontend в `src/`.
2. Перенести backend в `server/` (`server.js` -> `server/index.js`).
3. Обновить пути импорта в `vite.config.ts`, `tsconfig.json`, `index.html`.
4. Проверить сборку `npm run dev`.
