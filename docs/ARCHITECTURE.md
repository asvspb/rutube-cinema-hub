# Архитектура проекта Rutube Cinema Hub

## Обзор системы

Rutube Cinema Hub - это веб-приложение для просмотра и анализа видео с Rutube с возможностью получения расширенной информации о фильмах и сериалах через AI. Архитектура приложения следует принципам Clean Architecture с четким разделением на UI, доменную логику и инфраструктурные компоненты.

## Уровни архитектуры

### 1. UI уровень (Presentation Layer)
- **Фронтенд**: React 18.3.1 + TypeScript
- **Стилизация**: Tailwind CSS + Framer Motion для анимаций
- **Компоненты**: Следуют принципам модульности и переиспользуемости
- **Состояние**: Управление состоянием через React Hooks и кастомные хуки

### 2. Доменный уровень (Domain Layer)
- **Типы данных**: Определены в `types/` по доменам
- **Бизнес-логика**: Реализована в сервисах (`services/`)
- **Кастомные хуки**: Инкапсулируют логику управления состоянием

### 3. Инфраструктурный уровень (Infrastructure Layer)
- **Backend**: Express.js сервер
- **API**: Прокси для обхода CORS, интеграция с LLM провайдерами
- **Хранилище**: localStorage и потенциально IndexedDB
- **Сеть**: Обработка HTTP-запросов, управление прокси-серверами

## Ключевые архитектурные решения

### 1. Мульти-стратегия извлечения данных из Rutube
- **Цель**: Обеспечить стабильность получения данных при возможных изменениях API Rutube
- **Реализация**: 
  - API → Redux state → HTML scraping → regex
  - Graceful degradation: если API недоступен, извлекаем данные из Redux-стейта в HTML, затем из скриптов через regex
- **Файл**: `services/rutubeService.ts`

### 2. Гибридное проксирование с race-логикой
- **Цель**: Обеспечить доступность данных из Rutube из регионов с ограничениями
- **Реализация**:
  - Локальный прокси (`:9230`) + публичные прокси с отслеживанием статуса
  - Proxy race: параллельный запуск с выбором первого успешного ответа
- **Файл**: `server/index.js`, `services/rutubeService.ts`

### 3. Dual LLM Provider с авто-fallback
- **Цель**: Обеспечить надежность получения AI-обогащенной информации
- **Реализация**:
  - Автоматическое определение доступных провайдеров (Gemini/Mistral)
  - При ошибке одного провайдера — прозрачный переход на другой
  - JSON-схема для снижения галлюцинаций у Gemini
- **Файл**: `server/index.js`

### 4. Локальная база фильмов как first-pass оптимизация
- **Цель**: Снизить количество дорогостоящих AI-запросов
- **Реализация**:
  - Сначала ищем в локальной базе (~1250 фильмов)
  - Только при отсутствии — вызываем LLM
  - Fuzzy-matching по названию с нормализацией и scoring
- **Файл**: `services/top250Data.ts`

## Поток данных (Data Flow)

```
Rutube API/HTML ──→ rutubeService (мульти-стратегия) ──→ App.tsx state ──→ VideoCard
                         ↑                                      ↓
                    Proxy (local → public fallback)        localStorage (persist)
                                                                ↓
Movie title ──→ top250Data (локальная БД) ──→ LLM API (Gemini/Mistral) ──→ metadataCache
```

## Безопасность

### 1. Валидация прокси-запросов
- Проверка домена `rutube.ru` в `server/index.js`
- Ограничение доступа к внутренним ресурсам

### 2. CORS
- Ограничение origins для предотвращения CSRF-атак
- Настройка безопасных заголовков

### 3. Rate Limiting
- Ограничение количества запросов к API
- Предотвращение abuse использования ресурсов

## Мониторинг и логирование

### 1. Структурированные логи
- JSON-формат для удобства анализа
- Уровни логирования (debug/info/warn/error)
- Correlation ID для отслеживания запросов

### 2. Метрики
- Latency прокси (p50, p95, p99)
- Доля ошибок по стратегиям парсинга
- Успешность LLM-запросов по провайдерам
- Скорость импорта каналов/плейлистов

## Масштабируемость

### 1. Кэширование
- In-memory кэш видеоинформации
- Кэширование LLM-ответов
- Persistence через localStorage/IndexedDB

### 2. Виртуализация списков
- Для больших коллекций видео
- Оптимизация производительности рендеринга

## Технический стек

### Frontend
- **React 18.3.1**: Библиотека для создания пользовательских интерфейсов
- **TypeScript**: Статическая типизация

- **Express 5.2.1**: Web framework для Node.js

- **Vite 6.2.0**: Быстрая среда разработки и сборки
- **ESLint/Prettier**: Контроль качества кода
- **Jest/React Testing Library**: Тестирование
