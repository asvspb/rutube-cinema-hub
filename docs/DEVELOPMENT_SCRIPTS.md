## Скрипты "одной кнопкой"

### dev-all-in-one.sh

Основной скрипт для запуска всех необходимых сервисов одним действием:

- Запускает Vite сервер на порту 9229
- Запускает backend сервер на порту 9230
- Перезапускает backend при изменениях в файлах
- Тестирует важные функциональные элементы

#### Запуск

```bash
# Способ 1: Напрямую
./scripts/dev-all-in-one.sh

# Способ 2: Через npm
npm run dev:all
```

#### Функциональность

Скрипт автоматически:

1. Проверяет наличие необходимых зависимостей
2. Устанавливает `concurrently` и `nodemon` при необходимости
3. Запускает Vite и backend серверы параллельно
4. Отслеживает изменения в серверных файлах и перезапускает backend
5. Выполняет тестирование функциональных элементов после запуска

#### Тестируемые элементы

- Доступность Vite сервера (порт 9229)
- Доступность backend сервера (порт 9230)
- Работоспособность прокси-эндпоинта
- Доступность KinoRate AI эндпоинта

- **Frontend (Vite)**: порт 9229
- **Backend (Express)**: порт 9230
- **Прокси**: `/api/proxy` на backend сервере
- **KinoRate AI**: `/api/ai/kinorate/*` на backend сервере
