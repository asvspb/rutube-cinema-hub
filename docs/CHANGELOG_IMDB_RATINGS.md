# Изменения: Система рейтингов IMDB

## Дата: 2026-02-04

### Реализованные изменения

#### 1. ✅ Удалена функция "Уточнить рейтинг (База)" из меню плейлиста
- Удалена неактуальная функция массового обогащения из локальной базы
- Очищен код в `App.tsx` и `CategoryFilter.tsx`

#### 2. ✅ Очистка кеша IMDB рейтингов
- Создан скрипт для очистки всех существующих IMDB рейтингов: `tmp_rovodev_clear_imdb_cache.js`
- **Инструкция**: Откройте консоль браузера (F12) и выполните:
  ```javascript
  // Очистка кеша IMDB рейтингов
  const cacheKey = 'rutube_cinema_v2_metadata_cache';
  const cache = JSON.parse(localStorage.getItem(cacheKey) || '{}');
  Object.keys(cache).forEach(key => {
    if (cache[key].imdbRating > 0) delete cache[key];
  });
  localStorage.setItem(cacheKey, JSON.stringify(cache));
  location.reload();
  ```

#### 3. ✅ Двухэтапная система запроса рейтингов
**Первая попытка**: Автоматически проверяется локальная база Top 250/1000
- Кнопка AI появляется при наведении на видео без рейтинга
- Тултип: **"Запросить в локальной базе"**
- При клике мгновенно проверяется локальная база данных
- Если найдено - сохраняется с `dataSource: 'local'`
- Если не найдено - создается запись с `aiAttempts: 0`

**Последующие попытки**: Запрос через AI с Google Search
- Кнопка AI снова появляется, если рейтинг не найден
- Тултип: **"Запросить через поисковик"**
- При клике отправляется запрос к Gemini AI
- Результат сохраняется с `dataSource: 'ai'` и инкрементируется `aiAttempts`

#### 4. ✅ Визуальное различие источников данных

**Рейтинги из локальной базы (Top 250/1000)**:
```
┌─────────────────────────┐
│ 👑 Top IMDB: 9.3        │  ← Корона + текст "Top IMDB"
└─────────────────────────┘
```
- Иконка **короны** (👑) темно-синего цвета внутри желтого бейджа
- Текст: **"Top IMDB"** вместо просто "IMDB"
- Подробный тултип при наведении:
  - Оригинальное название фильма
  - Год выпуска
  - Награды (Оскары)
  - Источник: "Из Top 250/1000"

**Рейтинги через AI (Google Search)**:
```
┌─────────────────────────┐
│ IMDB: 7.8 🔗            │  ← Кликабельная ссылка
└─────────────────────────┘
```
- Стандартный текст: **"IMDB"** без короны
- **Кликабельная ссылка** - открывает страницу IMDB в новой вкладке
- Эффект hover: Цвет меняется на более темный желтый

#### 5. ✅ Ссылка на оригинальную страницу IMDB
- Для рейтингов полученных через AI, бейдж становится ссылкой
- Клик открывает страницу фильма на IMDB в новой вкладке
- URL извлекается из источников Google Search

### Как это работает для пользователя

1. **Видео без рейтинга**: 
   - Наведите на карточку → Появится кнопка "✨ AI"
   - Кликните → Мгновенная проверка в Top 250/1000
   
2. **Найдено в локальной базе**:
   - Появится бейдж "👑 Top IMDB 9.3"
   - Наведите для деталей (название, год, награды)
   
3. **Не найдено в локальной базе**:
   - Кнопка "✨ AI" снова появится при наведении
   - Кликните → Запрос к AI (Google Search)
   - Если найдено → Появится "IMDB 7.8" (кликабельная ссылка)
   
4. **Повторные неудачные попытки**:
   - Кнопка будет появляться, пока не найден рейтинг
   - Счетчик попыток сохраняется для аналитики

### Преимущества

✅ **Скорость**: Локальная база проверяется мгновенно  
✅ **Точность**: AI использует Google Search для актуальных данных  
✅ **Экономия**: AI запросы только для фильмов вне топа  
✅ **Прозрачность**: Четко видно, откуда взят рейтинг  
✅ **Удобство**: Прямая ссылка на IMDB для дополнительной информации

**Примечание**: Для применения изменений необходимо очистить кеш IMDB рейтингов в браузере (см. инструкцию выше).
