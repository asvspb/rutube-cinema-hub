# Технические задания для AI-агентов (расширенные)

## Общие правила
- Читать: `docs/PROJECT_RULES.md`, `docs/PROJECT_RULES_EXTENDED.md`, `docs/ARCHITECTURE.md`.
- Не менять API без обратной совместимости.
- Не добавлять зависимости без явной необходимости.
- Обновлять документацию при изменениях.

## Глоссарий
- **AC** — критерии приемки (Acceptance Criteria).
- **Deps** — зависимости от других задач.

---

## Агент 0: Миграция структуры проекта (обязательный подготовительный этап)
**Цель**: выровнять структуру с планом (`src/`, `server/`).

**Входные условия**:
- Проект текущий: `App.tsx`, `server/index.js`, `services/` в корне (до миграции: `server.js`).

**Задачи**:
1. Перенести фронтенд в `src/`:
   - `App.tsx`, `index.tsx`, `types.ts`, `components/`, `hooks/`, `services/`.
2. Перенести сервер в `server/`:
   - `server.js` -> `server/index.js`.
3. Обновить `vite.config.ts`, `tsconfig.json`, `index.html` и пути импортов.
4. Обновить `package.json` scripts (если пути меняются).

**AC**:
- `npm run dev` запускается без ошибок.
- Frontend и backend работают как до миграции.
- Все импорты резолвятся корректно.

**Deps**: нет.

---

## Агент 1: Безопасность и прокси
**Цель**: повысить безопасность `/api/proxy`.

**Deps**: Агент 0.

**Задачи**:
- Allowlist доменов (`rutube.ru`, `*.rutube.ru`, `api.rutube.ru`).
- Блокировка приватных IP/localhost (IPv4/IPv6).
- Rate limit `express-rate-limit` для `/api/proxy` и `/api/ai/*`.
- CORS whitelist (prod + dev origins).
- Добавить security headers (Helmet или вручную).

**AC**:
- Запросы на неразрешённые домены отклоняются с 403.
- Попытки доступа к `127.0.0.1`, `10.x`, `192.168.x` блокируются.
- Лимит запросов срабатывает при превышении.
- CORS блокирует неизвестные origin.

**Ограничения**:
- Не ломать существующий `/api/proxy` контракт.

## Агент 2: Декомпозиция App.tsx
**Цель**: сократить `App.tsx` до < 300 строк и вынести логику.

**Deps**: Агент 0.

**Задачи**:
- Вынести состояние в хуки: `useChannels`, `useVideoCache`, `useFilters`, `useVideoStatus`, `useMetadata`.
- Разделить UI на `Header`, `VideoGrid`, `Modals`, `Sidebar`.
- Удалить `@ts-ignore`.
- Добавить строгую типизацию.

**AC**:
- `App.tsx` < 300 строк.
- Нет `@ts-ignore`.
- UI и поведение не изменились функционально.

## Агент 3: Backend рефакторинг
**Цель**: разделить `server/index.js` на модули.

**Deps**: Агент 0, Агент 1.

**Задачи**:
- Вынести роуты в `server/routes/`.
- Вынести LLM сервисы в `server/services/llm/*`.
- Добавить `/health`.
- Ввести `logger` сервис.

**AC**:
- Все старые эндпоинты работают.
- `/health` возвращает статус и версии сервисов.
- Логи структурированные.

## Агент 4: Тестирование

**Deps**: Агент 2, Агент 3.

**Задачи**:

**AC**:

- CI pipeline падает при низком coverage.
