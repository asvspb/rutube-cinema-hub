# ADR-001: Использование многоуровневой стратегии получения данных из Rutube

## Статус

Принято

## Дата

2026-02-09

## Контекст

Rutube не предоставляет официального API для получения данных о видео с каналов. В то же время, прямой парсинг HTML-страниц может быть нестабильным из-за частых изменений в структуре сайта. Также существуют ограничения доступа к Rutube из некоторых регионов, требующие обхода CORS и блокировок.

## Решение

Реализовать многоуровневую стратегию получения данных из Rutube с использованием следующих подходов в порядке приоритета:

1. **API-запросы** - попытка получить данные через официальные или полуофициальные эндпоинты Rutube
2. **Извлечение из Redux-состояния** - парсинг HTML-страницы и извлечение данных из `window.reduxState`
3. **Прямой парсинг скриптов** - поиск JSON-подобных структур в теле HTML-страницы с помощью регулярных выражений
4. **Использование TV-приложений API** - альтернативные эндпоинты, которые могут быть стабильнее веб-версии

Для обхода CORS и региональных ограничений реализовать гибридное проксирование:

- Локальный прокси-сервер (приложение запускается с backend-частью)
- Публичные прокси-сервисы в качестве fallback'а
- Race-логика для выбора наиболее быстрого ответа

## Последствия

### Положительные

- Повышенная стабильность получения данных
- Возможность работы из регионов с ограничениями
- Гибкость в случае изменений на стороне Rutube
- Graceful degradation при частичных сбоях

### Отрицательные

- Увеличенная сложность логики получения данных
- Потенциальные задержки при fallback'ах на менее быстрые стратегии
- Зависимость от публичных прокси-сервисов (потенциально ненадежные)

## Альтернативы

1. **Использование только одного метода** - слишком хрупкое решение, легко ломается при изменениях на стороне Rutube
2. **Использование Selenium/puppeteer** - избыточное решение, высокие требования к ресурсам, медленная работа
3. **Полный отказ от получения данных** - делает приложение бесполезным

## Решение

Выбрана многоуровневая стратегия как наиболее устойчивое решение для получения данных из нестабильного внешнего источника.
