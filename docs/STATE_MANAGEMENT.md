# Управление состоянием в Rutube Cinema Hub

## Обзор

В проекте Rutube Cinema Hub используется комбинация React-хуков для управления состоянием на клиентской стороне. В текущей реализации основное состояние сосредоточено в компоненте `App.tsx`, но в будущем планируется декомпозиция на кастомные хуки и потенциальный переход к более мощному решению типа Zustand.

## Текущая архитектура состояния

### App.tsx (монолитное состояние)

На данный момент основное состояние приложения находится в главном компоненте `App.tsx` и включает:

- `channels`: список добавленных каналов
- `videos`: видеозаписи, полученные с каналов
- `playlists`: плейлисты пользователя
- `selectedChannel`: выбранный канал
- `selectedPlaylist`: выбранный плейлист
- `filters`: фильтры для видео
- `sortOrder`: порядок сортировки
- `viewMode`: режим отображения (сетка/список)
- `gridColumns`: количество колонок в сетке
- `loadingStates`: различные состояния загрузки
- `errorMessages`: сообщения об ошибках
- `metadataCache`: кэш метаданных фильмов
- `videoStatuses`: статусы видео (лайк, просмотрено, отложенное)
- `userPreferences`: пользовательские настройки
- `modalStates`: состояния модальных окон
- `searchQuery`: поисковый запрос
- `pagination`: информация о пагинации

## Кастомные хуки (планируемая архитектура)

Для улучшения архитектуры планируется декомпозиция состояния на кастомные хуки:

### useChannels

- Управляет списком каналов
- Операции: добавление, удаление, переименование
- Хранит состояние загрузки каналов
- Обрабатывает импорт каналов из плейлистов

### usePlaylistsImport

- Логика импорта плейлистов
- Обработка URL плейлистов
- Конвертация плейлистов в каналы

### useVideoCache

- Кэширование видеозаписей
- Управление памятью кэша
- Дедупликация видео

### useFilters

- Управление фильтрами видео
- Сохранение фильтров между сессиями
- Сброс фильтров

### useHistory

- История просмотров
- Управление записями истории
- Очистка истории

### useVideoStatuses

- Статусы видео (лайк, просмотрено, отложенное)
- Циклическое переключение статусов
- Синхронизация с localStorage

### useNotifications

- Управление уведомлениями и тостами
- Отображение ошибок и информационных сообщений

## Хранилище данных

### localStorage

- Используется для персистентного хранения данных между сессиями
- Ключи разделяются для гостевого и авторизованного режимов
- Содержит: каналы, плейлисты, настройки, историю, статусы видео

### StorageService (планируемая абстракция)

- Типизированный интерфейс для работы с localStorage
- Обработка ошибок при работе с хранилищем
- Валидация данных при чтении/записи

## Потоки данных

### Получение видео с Rutube

```
Пользователь выбирает канал
         ↓
useChannels возвращает URL канала
         ↓
rutubeService.fetchVideos() делает запрос через прокси
         ↓
Данные нормализуются и кэшируются в useVideoCache
         ↓
Видео отображаются в UI
```

### Обогащение метаданными через AI

```
Видео без метаданных
         ↓
Проверка в top250Data (локальная база)
         ↓
Если не найдено → запрос к LLM через сервер
         ↓
Результат сохраняется в metadataCache
         ↓
UI обновляется с новыми данными
```

- Разделение тяжелых состояний

### 2. Управление памятью

- Очистка подписок при размонтировании
- Ограничение размера кэшей
- Удаление устаревших данных

### 3. Обработка ошибок

- Централизованная обработка ошибок
- Отображение пользовательских сообщений
- Восстановление после ошибок

## Будущие улучшения

### 1. Переход на Zustand/Pinia

- Более предсказуемое управление глобальным состоянием
- Лучшая тестируемость
- Возможность отладки и девтулзов

### 2. Миграция на IndexedDB

- Более надежное хранение данных
- Поддержка сложных запросов
- Лучшая производительность для больших объемов данных

### 3. Синхронизация между устройствами

- Возможность синхронизации настроек и данных пользователя
- Обработка конфликтов синхронизации
- Оффлайн-режим

## Структура типов состояния

### Channel

```typescript
interface Channel {
  id: string;
  name: string;
  url: string;
  addedDate: string;
  videoCount?: number;
}
```

### Video

```typescript
interface Video {
  id: string;
  title: string;
  thumbnail: string;
  duration: string;
  uploadedDate: string;
  views: string;
  channel: string;
  url: string;
  metadata?: MovieRatingData; // Данные из AI
  status?: 'liked' | 'watched' | 'watch_later' | null;
}
```

### MovieRatingData

```typescript
interface MovieRatingData {
  title: string;
  originalTitle: string;
  year: string;
  kpRating: number;
  kpVotes: string;
  imdbRating: number;
  imdbUrl?: string;
  description: string;
  sources?: string[];
  awards?: string[];
  dataSource?: 'local' | 'ai';
  aiAttempts?: number;
}
```
