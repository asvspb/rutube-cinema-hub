Техническое задание: разделение кнопок статуса/лайка на карточке видео + исправление перекрытия sticky-меню

Контекст
- Проект: Rutube Cinema Hub (frontend на React + Tailwind).
- Карточка видео: components/VideoCard.tsx.
- Sticky-меню сортировки/сетки: App.tsx (блок с классами "sticky top-16 z-30").

Проблемы
1) В текущей реализации кнопка статуса (Просмотрено/Посмотреть позже/Понравилось) размещена в левом нижнем углу карточки и визуально перекрывает/пролезает поверх липкого меню навигации.
2) Одна кнопка циклически переключает статусы “Liked/Watched/Watch later”. Нужно разделить управление:
   - отдельная кнопка для “Просмотрено/Посмотреть позже”
   - отдельная кнопка для “Лайк/Дизлайк” (создать)
   - кнопки должны располагаться рядом

Цель
- Устранить перекрытие sticky-меню элементами карточек.
- Разделить кнопку статуса на две: (а) просмотрено/смотреть позже, (б) лайк/дизлайк.
- Сохранить текущую UX-парадигму: кнопки показываются при hover, с подсказками.

Требования
1) Исправление перекрытия sticky-меню
   - Уточнить z-index слоёв: sticky-меню должно быть выше карточек и их кнопок.
   - Предпочтительно: уменьшить z-index у кнопок/оверлеев карточки или увеличить у sticky-меню.
   - Проверить элементы в VideoCard.tsx с z-индексами (например, контейнеры с "z-30" / "z-20" / "z-50") и их эффект на перекрытие.
   - Критерий: при скролле sticky-меню не должно перекрываться кнопками карточек.

2) Разделение кнопок статуса
   - Текущее поведение: status (liked/watched/watch_later) хранится в App.tsx и передаётся в VideoCard.
   - Нужно разделить на два независимых состояния:
     a) “Просмотрено/Смотреть позже” — бинарное состояние (например: watched | watch_later | none).
     b) “Лайк/Дизлайк” — новое состояние (например: liked | disliked | none).
   - Обновить модель статусов (в App.tsx) и логику хранения/восстановления из localStorage.
   - Обновить UI карточки:
     - Отдельная кнопка (Просмотрено/Смотреть позже) — цикличное переключение: none -> watched -> watch_later -> none.
     - Отдельная кнопка (Лайк/Дизлайк) — цикличное переключение: none -> liked -> disliked -> none.
     - Кнопки располагаются рядом (горизонтально) в левом нижнем углу карточки.
     - Каждая кнопка имеет собственный tooltip и цветовые состояния.

Точки в коде
- components/VideoCard.tsx
  - Блок "Status Toggle Button with Tooltip (Bottom Left)" — переработать в две кнопки.
  - Добавить второй контрол (иконки: Heart/ThumbsUp/ThumbsDown или Heart + X и т.д.).
  - Скорректировать z-index и контейнеры hover.
- App.tsx
  - Состояние videoStatuses (Record<string, ...>) — разделить на два объекта/структуру.
  - Логика обновления статусов (handleStatusToggle и зависимые функции) — разделить на две функции.
  - Обновить сохранение/загрузку из localStorage (новые ключи).

UX детали
- Кнопки должны появляться при hover на карточке (как сейчас).
- Для активных состояний кнопки остаются видимыми (opacity: 100%).
- Tooltip текст:
  - Просмотрено/Посмотреть позже: «Просмотрено», «Посмотреть позже», «Убрать отметку»
  - Лайк/Дизлайк: «Нравится», «Не нравится», «Убрать оценку»

Acceptance Criteria (AC)
1) Sticky-меню (sort/grid) всегда поверх карточек при прокрутке, элементы карточки не перекрывают его визуально.
2) В карточке есть две отдельные кнопки рядом в левом нижнем углу:
   - Просмотрено/Посмотреть позже
   - Лайк/Дизлайк
3) Состояния кнопок независимы и корректно сохраняются/восстанавливаются из localStorage.
4) Нет регрессий в отображении карточки и hover эффектах.

Примечания
- Не добавлять новые зависимости.
- Сохранять стиль Tailwind и текущую визуальную эстетику.
- Изменения должны быть изолированы от серверной части.
